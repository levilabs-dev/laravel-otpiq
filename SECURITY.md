This package handles OTPIQ API keys (`sk_live…`, `sk_dev…`) and processes outbound OTP and messaging traffic. Please report security issues responsibly, as described below.

## Supported Versions

| Version          | Supported |
| ---------------- | --------- |
| 1.x (and `main`) | Yes       |
| < 1.0            | No        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Preferred: GitHub private reporting

1. Open the [Security tab](https://github.com/levilabs-dev/laravel-otpiq/security) for this repository.
2. Click **Report a vulnerability**.

### Alternative: email

Contact us privately (include repo name `levilabs/laravel-otpiq` in the subject):

- **Levi Labs:** [hello@levilabs.dev](mailto:hello@levilabs.dev)
- **Nizam Omer:** [nizam@nizaamomer.com](mailto:nizam@nizaamomer.com)
